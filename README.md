# SolidityMount

SolidityMount is a decentralized, real-time data synchronization platform, utilizing a multi-node architecture for fault-tolerant, distributed management.

SolidityMount is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/SolidityMount.git`
2. `cd SolidityMount`
3. Install in editable mode: `pip install -e .`

## Configuration

SolidityMount is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
